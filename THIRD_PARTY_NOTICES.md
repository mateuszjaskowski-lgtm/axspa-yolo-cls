# Third-party components

The repository's existing `LICENSE` is preserved. It covers the repository code only and does not relicense upstream software, pretrained model assets, study images or third-party material.

- Ultralytics code and pretrained YOLO assets retain their upstream licensing terms. The existing repository license notice explicitly identifies the YOLO11l-cls base asset as AGPL-3.0. The same repository license must not be assumed to cover YOLO26 or any other externally obtained model asset.
- PyTorch, torchvision and ImageNet-pretrained comparator assets retain their respective upstream notices and terms.
- Source URLs, filenames and SHA-256 hashes of the actual pretrained initialization files are preserved in the per-run metadata.

No pretrained initialization file, selected study checkpoint or source PNG is included in this Git tree.
